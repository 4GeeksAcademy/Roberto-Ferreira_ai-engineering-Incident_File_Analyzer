# Memory Bank

This folder records the persistent project context for the Brasaland AI Engineering milestone.

## Purpose

The memory bank is the repo's durable source of truth for business intent, project constraints, and
implementation decisions. It prevents the project from drifting into scaffold-only work that cannot be
explained or reused.

## Files

- `projectbrief.md` — business objective, stakeholder context, and product goals
- `techContext.md` — verified stack, architecture, constraints, and design decisions
- `progress.md` — what is implemented, what is verified, and what remains

## How to use it

Keep this folder updated whenever a meaningful implementation step is completed. If the project adds a
new feature, agent, skill, or app, capture the state in the memory bank before treating the work as
finished.
