# OpenClaw project metadata

This folder is kept for project-scoped operational metadata and agent-runtime notes.

## Purpose

It provides a stable, repo-local place for automation metadata, documentation hooks, and future
runtime generated output that belongs to the project itself rather than the app code.

## Notes

- This repository is meant to be a company monorepo with multiple apps, agents, skills, and shared modules.
- The folder is intentionally lightweight and does not contain secrets or environment configuration.
- It should remain machine-readable and safe to inspect in version control.
